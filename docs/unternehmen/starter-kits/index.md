# Starter Kits

## Go-Live-Checkliste

Die Checkliste für den Launch einer Website ist eine [Issue-Vorlage im Org-Repo `.github`](https://github.com/profitlich-ch/.github/blob/main/.github/ISSUE_TEMPLATE/go-live.md). Sie steht in jedem Repository unter *New issue* zur Auswahl, sofern es keine eigenen Issue-Vorlagen hat. Beim Eröffnen den nicht zutreffenden CMS-Abschnitt löschen.
